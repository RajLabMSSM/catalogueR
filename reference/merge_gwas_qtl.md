# Merge GWAS with QTL

Merge GWAS data (query) and QTL data (results).

## Usage

``` r
merge_gwas_qtl(query_dat, qtl.subset, verbose = TRUE)
```

## Arguments

- verbose:

  Show more (`=TRUE`) or fewer (`=FALSE`) messages.
