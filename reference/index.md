# Package index

## eQTL Catalogue queries

Functions for querying and searching the eQTL Catalogue

- [`eQTLcatalogue_query()`](https://rajlabmssm.github.io/catalogueR/reference/eQTLcatalogue_query.md)
  :

  Iterate queries to *eQTL Catalogue*

- [`eQTLcatalogue_fetch()`](https://rajlabmssm.github.io/catalogueR/reference/eQTLcatalogue_fetch.md)
  : Query eQTL Catalogue

- [`eQTLcatalogue_list_datasets()`](https://rajlabmssm.github.io/catalogueR/reference/eQTLcatalogue_list_datasets.md)
  : List available eQTL datasets

- [`eQTLcatalogue_search_metadata()`](https://rajlabmssm.github.io/catalogueR/reference/eQTLcatalogue_search_metadata.md)
  : Search eQTL Catalogue metadata

- [`eQTLcatalogue_annotate_tissues()`](https://rajlabmssm.github.io/catalogueR/reference/eQTLcatalogue_annotate_tissues.md)
  : Annotate QTL datasets with metadata

- [`eQTLcatalogue_example_queries()`](https://rajlabmssm.github.io/catalogueR/reference/eQTLcatalogue_example_queries.md)
  : Paths to example eQTL Catalogue query results

## Colocalization

Run and visualize colocalization analyses with coloc

- [`COLOC_run()`](https://rajlabmssm.github.io/catalogueR/reference/COLOC_run.md)
  : Iteratively run coloc on merged GWAS-QTL datatables
- [`COLOC_merge_res()`](https://rajlabmssm.github.io/catalogueR/reference/COLOC_merge_res.md)
  : Prepare data for coloc plot
- [`COLOC_get_example_res()`](https://rajlabmssm.github.io/catalogueR/reference/COLOC_get_example_res.md)
  : Example colocalization results
- [`COLOC_heatmap()`](https://rajlabmssm.github.io/catalogueR/reference/COLOC_heatmap.md)
  : Plot summary of coloc tests: heatmap
- [`COLOC_corplot()`](https://rajlabmssm.github.io/catalogueR/reference/COLOC_corplot.md)
  : Plot summary of coloc tests: heatmap
- [`COLOC_plot_loci()`](https://rajlabmssm.github.io/catalogueR/reference/COLOC_plot_loci.md)
  : Faceted Manhattan plots of QTL datasets

## Gene ID conversion

Convert between Ensembl and HGNC gene identifiers

- [`ensembl_to_hgnc()`](https://rajlabmssm.github.io/catalogueR/reference/ensembl_to_hgnc.md)
  : Convert ENSEMBL IDs to HGNC gene symbols
- [`hgnc_to_ensembl()`](https://rajlabmssm.github.io/catalogueR/reference/hgnc_to_ensembl.md)
  : Convert HGNC gene symbols to ENSEMBL IDs
